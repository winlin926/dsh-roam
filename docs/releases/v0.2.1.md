# dsh-roam 0.2.1

首个公开版本：把电脑上的 DeepSeek Harness 会话漫游到手机。手机浏览器扫码即用；AI-HUB App 共用同一地址和配对码。

## 亮点

- 浏览器零安装：会话列表、继续对话、新建会话、切换模型、发送和取消。
- AI-HUB App：局域网扫码配对，公网手动填同一域名和配对码。
- 公网入口：Cloudflare 快速隧道、pinggy 兜底、固定域名 + Let's Encrypt 证书自动续期。
- 设置面板重做：桌面 954×501px，390px 宽无横向溢出；浏览器/AI-HUB 标签页、行内密码编辑、折叠诊断。
- 安全加固：管理接口回环 Host 校验、公网强制 HTTPS、AI-HUB 只接受可吊销设备凭据、配对全局失败预算、证书私钥 Windows ACL 收紧、浏览器会话 30 天绝对过期。

## 安装

```bash
dsh plugin --profile web add dsh-roam@0.2.1
```

重启 DSH，打开 **设置 → 连接手机**。

## 已知限制

- AI-HUB 配对二维码包含固定连接密码。二维码旁已提示不要截图外发；下一版本将改为一次性 pairing token。
- 修改连接密码只影响浏览器会话，不吊销已配对的 AI-HUB 设备；移除设备才会吊销该设备凭据。
- 设备在线状态取自事件流长连接，退后台或断网会立即显示离线，不代表推送可达。
- 固定域名证书流程按 frpc / SakuraFrp 工作目录约定实现；其他反向代理需要自行部署证书。

## 数据与隐私

数据保存在 `%USERPROFILE%\.dsh\dsh-roam` 与兼容的 `%USERPROFILE%\.dsh\relay*.json`。手机 IP 的归属地查询使用本机离线库，不上传第三方。没有遥测。
