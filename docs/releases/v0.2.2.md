# dsh-roam 0.2.2

0.2.1 的补丁版本，修复真机验收发现的两个问题。

## 修复

- **移除设备失败**：设置面板点「移除」曾返回 `mobileDevices is not defined`。现在会先吊销设备凭据，再从本机设备台账删除，并补了路由回归测试。
- **浏览器状态误报**：关闭手机页面后，面板仍长期显示「浏览器已连接」。现在只有最近 30 秒内发过真实请求的浏览器会话才算在线；超过 30 秒自动变为未连接，重新打开页面后恢复。

## 升级

```bash
dsh plugin --profile web add dsh-roam@0.2.2
```

已配对设备和连接密码保留，不需要重新配对。重启 DSH 后生效。

## 验证

- `pnpm test`：18 个测试文件、206 个用例全绿。
- 真机验收：局域网浏览器、公网浏览器、AI-HUB 局域网、AI-HUB 公网均已通过；本版本补测设备移除。
