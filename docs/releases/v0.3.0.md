# dsh-roam 0.3.0

AI-HUB 二维码改为一次性配对码。

## 变更

- 二维码里不再包含固定 6 位连接密码，而是 5 分钟有效、成功配对一次即作废的一次性配对码。
- 手动配对 AI-HUB 仍使用固定密码；浏览器公网入口的密码不变。
- 一次性码过期或被使用后，面板轮询会自动生成新码。
- AI-HUB 移动 API 不可用时显示具体原因，不再一直显示“二维码生成中”。

## 安全边界

- 二维码截图只有在 5 分钟内、且未被使用过时才可能被滥用；过期后无效。
- 固定密码仍用于手动配对和浏览器入口，继续受 10 次 / 10 分钟的全局限速保护。
- 已配对设备仍使用可吊销的设备凭据，不受二维码轮换影响。

## 升级

```bash
dsh plugin --profile web add dsh-roam@0.3.0
```

重启 DSH 后生效；已配对设备、连接密码和公网配置保留。

## 验证

- `pnpm test`：18 个测试文件、208 个用例全绿。
- 真机需要复测：AI-HUB 扫码配对、同一二维码第二次使用应失败、5 分钟后刷新、手动固定密码仍可配对。
