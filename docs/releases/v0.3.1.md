# dsh-roam 0.3.1

这是 AI-HUB 兼容版的安全修复版本，也是浏览器-only 1.0 之前的最后一个旧版本。

## 修复

- 公网配对不再依赖可被改写的 `Host`。请求带有 `Forwarded`、`X-Forwarded-*`、`X-Real-IP` 或 `CF-*` 时按公网入口处理；配置固定公网域名后，所有配对都必须输入连接密码。
- 删除按来源 IP 免 Cookie 放行和“同 IP 任意 Cookie 提升为会话”的逻辑。浏览器会话只接受服务端签发、未过期的 Cookie。
- AI-HUB 设备凭据只接受本机签发且仍有效的 `dshc_`；吊销后不能再通过伪造 `dshc_` 加旧 Bearer 继续访问。
- 移动 API 不可用时，移除设备返回 503 并保留本机台账，避免“台账已删、凭据仍有效”。
- 修复桌面页隧道错误文本未转义的问题。
- 面板轮询改为单飞并加超时；启动失败时显示错误和重试入口。

## 升级

```bash
dsh plugin --profile web add dsh-roam@0.3.1
```

重启 DSH 后生效。已保存的公网域名、连接密码、证书和 AI-HUB 设备凭据保持不变。局域网浏览器如果之前依赖无 Cookie 的同 IP 交接，升级后需要重新扫描二维码。
