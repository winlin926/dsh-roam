# dsh-roam 1.0.0

浏览器-only 大版本。手机端只保留浏览器，不再提供 AI-HUB App、移动 API 或设备凭据。

## 主要变化

- 移除 AI-HUB 入口、`/api/mobile/*`、设备台账、离线归属地库和 `dsh-mobile-plugin` 依赖。
- 移除独立的 `/desktop` 配对页和桌面 Cookie，连接手机统一在 DSH 设置面板完成。
- 设置面板重做：状态、同一 Wi-Fi / 任意网络、二维码、连接密码、公网设置和排障信息分层展示；窄屏纵向排列。
- 手机页默认打开会话列表；聊天页有会话标题、固定会话头和 44px 返回键，输入区适配 iPhone 底部安全区。
- 手机页允许缩放，浅色 muted 文本提升到可读对比度，中文界面不再出现 `Think`、`Preset`、`Deep diving...`。
- 继续使用一次性二维码令牌、公网 6 位密码、固定公网域名证书签发与临时隧道。

## 升级与回退

- 从 0.3.x 升级：保留 `settings.json`、`mobile-pairing-pin.json`、证书与公网配置；浏览器需要重新扫码。
- 需要 AI-HUB App：请使用 `dsh-roam@0.3.1` 或 `legacy/aihub` 分支。
- 1.0 不读取也不删除旧版 `mobile-devices.json`、`relay-device-credentials.json`、`ip2region/`，回退 0.3.1 仍可使用。

## 安全边界

- `/phone-bridge/*` 只接受本机回环请求并校验 Host 与同源。
- 二维码令牌 5 分钟有效、一次性；公网入口必须输入 6 位连接密码。
- 浏览器会话只认服务端 Cookie，30 天绝对过期；插件重启后需要重新扫码。
- 本版本没有应用层端到端加密。公网 TLS 在 Cloudflare、Pinggy、frps 或反向代理处终止；对内容保密有更高要求时，请使用自己控制的固定域名与反向代理，或只在可信局域网使用。

## 安装

```bash
dsh plugin --profile web add dsh-roam@1.0.0
```

重启 DSH 后打开 **设置 → 连接手机**。
