# dsh-roam 1.1.0

手机端从“能看会话”升级为“能远程办公”：首页直接开工，图片、文件、审批、队列、分页和会话管理都在手机上完成。

## 主要变化

- 导航改为左上角 ☰ 打开的共用左侧抽屉，集中工作区切换、新建任务、搜索、最近 / 已归档会话与连接状态。首页默认呈现纯净的新建任务状态，不自动打开最近聊天、不展示最近会话列表；发送前不创建会话，输入后直接创建并发送首条消息，再进入带独立会话头部的全屏聊天。模型、思考强度与会话模式从输入卡设置，工作区可从抽屉或首页输入卡下方切换；品牌资源换成 DeepSeek 鲸鱼图标（浅色 / 深色两版）。
- 手机主界面拆为原生 HTML / CSS / ESM，由构建流程复制到 `lib/mobile/`；静态资源经鉴权与文件名白名单提供，主页面脚本限制为同源 CSP，重连与连接密码页独立保留。底部选择器、抽屉与弹层支持焦点约束、背景 inert 和返回关闭；消息按稳定 ID 更新节点，底部输入区随内容与可视视口自然布局，不依赖外部前端框架。
- 图片：相册多选、拍照、粘贴，canvas 压缩到长边 1568 / JPEG 0.85，单条最多 6 个附件，托盘支持删除与失败重试，纯图片消息可用。
- 历史图片：新增 `/api/attachment` 二进制端点，消息与工具结果里的图片按需加载，点击全屏查看。
- 工具审批：电脑端触发的 `approval/request` 同步到手机，可「允许一次」或「拒绝」；断线即失效，重复应答返回 409。
- 历史分页：`session.history` 支持 `beforeSeq`，消息顶部「加载更早」按 `seq` 去重并保持滚动位置。
- 运行中队列与 steer：生成中默认排队，队列 dock 支持编辑 / 移除 / 打断。
- 会话管理：重命名、归档 / 取消归档、按标题与内容搜索；搜索 provider 不可用时自动回退本地过滤。
- 文件上传：任意文件先换 `receiptId` 再随消息发送，历史显示文件卡片。
- PWA 基础：`manifest.webmanifest` 与 192 / 512 / 180 图标，可添加到主屏幕。
- 「连接手机」可查看活跃配对会话数与本次运行的设备列表，区分无活动与手动断开，不将历史配对误报为在线。

## 已知边界

- 手机端暂不支持回读任意文件：`session/attachment` 只授权图片，文件消息只显示名称与大小；需要回读时请在电脑上打开。
- 工具审批只在手机与桥接保持连接时可答；断开后审批失效，需回到电脑处理。
- Service Worker 与系统通知需要 HTTPS；局域网 HTTP 入口不支持。
- 当前 Node 自动化测试为 21 个文件、228 条；真实 Chrome 的 24 个交互用例通过，覆盖新建首页、抽屉导航、创建并发送、设置、审批 / 提问、队列、附件失败恢复、重命名 / 归档、历史滚动与慢请求跨会话恢复。测试使用移动视口和桩桥，不等于实体手机验证。
- 当前界面与新增功能尚未在 Android / iOS 真机验证；浏览器移动模拟不能替代真机测试。

## 升级

- 从 1.0.0 升级：`settings.json`、`mobile-pairing-pin.json`、证书与公网配置保持不变；浏览器会话仅保存在内存中，插件重启后需要重新扫码配对。
- 回退到 1.0.0 不需要迁移数据。

## 安全边界

- `/phone-bridge/*` 只接受本机回环请求并校验 Host 与同源。
- 二维码令牌 5 分钟有效、一次性；公网入口必须输入 6 位连接密码。
- 浏览器会话只认服务端 Cookie，30 天绝对过期；插件重启后需要重新扫码。
- 附件端点只读当前会话引用过的图片，返回 `private, max-age=3600`，不按路径读文件。
- 本版本没有应用层端到端加密；公网 TLS 在隧道或反向代理处终止。

## 安装

```bash
dsh plugin --profile web add dsh-roam@1.1.0
```
