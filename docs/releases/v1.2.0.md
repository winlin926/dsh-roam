# dsh-roam 1.2.0

**手机端不再只是“把会话搬过来”，而是更像一个随手可用的工作台。**

这版主要解决三个日常问题：想开新任务时首页太乱、想继续旧会话时找起来费劲、离开电脑后不知道有哪些连接。我们也把中英文安装说明重新写了一遍，新用户不必先读懂桥接、RPC 或证书，才能开始第一次连接。

## 这次你会直接感受到的变化

- **首页更干净了。** 打开就是新建任务：品牌、一个输入卡、必要的工作区提示。最近会话不再挤占首屏。
- **找会话更顺手了。** 左上角的 ☰ 会打开左侧抽屉，工作区切换、搜索、最近会话、已归档会话和连接状态都在这里。聊天中也可以直接换会话，不必先回首页。
- **聊天更像手机了。** 独立返回键、标题和运行状态、底部输入区，模型、思考强度和会话模式都改成了触屏更自然的底部选择面板。
- **连接情况更明白了。** 新增「连接设备」，可以查看当前活跃配对会话数、最近请求时间，以及无活动或手动断开状态。它不是重启前的完整历史设备库，也不把旧连接说成在线。

## 那些让体验更稳的小地方

- 输入框不再出现突兀的桌面式焦点框，键盘、底部安全区和输入区高度会一起工作。
- 流式回复按稳定消息身份更新，工具与思考的展开状态、图片和阅读位置不再轻易被重绘打断。
- 上翻阅读历史时不会被新消息强行拉回底部；加载更早消息也保留原来的阅读位置。
- 切换会话、关闭弹层、使用系统返回时，不会复活已经关闭的面板。
- 首发设置失败、发送失败或附件上传失败时，草稿和附件会留在真正需要重试的地方，不会消失或跑到另一个会话。
- 慢请求返回得太晚时，不会覆盖当前会话、错误解锁另一个加载任务或让运行状态倒退。
- 「连接设备」按浏览器配对会话计数，不把同一手机的不同浏览器或隐私窗口硬说成一台设备，也不把无活动直接当成断开。

## 手机端已有的工作能力

这版保留并接入了此前完成的移动功能：

- 相册多选、拍照、粘贴图片，自动压缩发送，历史图片可放大查看。
- 任意文件上传与历史文件卡片；文件内容暂时请在电脑端查看。
- 工具审批、Agent 提问、待办进度。
- 生成中的排队、编辑、移除和打断。
- 长会话加载更早、会话重命名、归档/取消归档、标题或内容搜索。
- 局域网、Cloudflare/Pinggy 临时隧道、固定域名与证书配置。
- PWA 基础：可添加到主屏幕；Service Worker 与系统通知需要 HTTPS，局域网 HTTP 不提供。

## 文档也更友好了

README 现在同时提供中文和英文，并加入实际的手机首页与「连接手机」设置截图。

它会先告诉你：这个插件能解决什么、怎样下载、第一次怎样连接；再解释各功能。没有域名时，可以直接使用现有的临时隧道，不需要先购买域名或配置公网 IP。

## 升级与兼容

- 从 1.x 升级不需要迁移数据。`settings.json`、连接密码、证书与公网配置保留。
- 浏览器会话仅保存在内存中，插件重启后需要重新扫码；旧 Cookie 不会被长期保留。
- 1.x 只做手机浏览器客户端，不恢复 AI-HUB App、移动 API、设备凭据或设备台账。旧 App 用户请继续使用 `0.3.1` / `legacy/aihub`。
- 本版本没有应用层端到端加密。公网 TLS 在 Cloudflare、Pinggy、frps 或反向代理处终止，敏感内容建议使用自己控制的网络与反向代理。
- 工具审批断线后需要在电脑端处理；重复应答会返回冲突，不会重复执行。

## 安装或升级

在 DSH 的 **设置 → 插件市场** 搜索 **dsh-roam**，安装后重启 DSH；或使用命令行：

```bash
dsh plugin --profile web add dsh-roam@1.2.0
```

装好后打开 **设置 → 连接手机**，扫码即可开始。
